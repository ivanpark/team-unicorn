# 엔트로피·정보 관리 연구 프로토콜 (v0.7.1)
**2026-10-13 · Team Unicorn — 개념 생성과 수 우주 건설의 공동 시험 항목**

## 핵심 질문
더 효율적인 건설이란 단순히 빠르게 달리거나 적은 수의 다리로 이동하는 것인가? 아니면 기존 정보를 잃지 않으면서 새로운 구조를 지속적으로 설계·구성하고 갱신하는 **정보·엔트로피 관리의 최적화**인가?

## 네 가지 구별할 양
1. **우주의 공간배치 정보 엔트로피** `H_U = -Σ_X P(X) log₂ P(X)`: 동일한 정수 범위의 가능한 합법적 3D 배치 X에 대한 명시적인 확률모형을 정의해야 계산 가능. 정수 자체의 고유 엔트로피가 아니다.
2. **유니콘/HQ의 설계 불확실성** `H_HQ = -Σ_g P(g | E_t) log₂ P(g | E_t)`: 지금까지의 피드백 E_t를 바탕으로 후보 gait 설계 g에 갖는 불확실성. 불확실성 감소가 항상 좋은 설계와 같은 것은 아님.
3. **표현·증명서의 길이/계산 복잡도:** 누적 소인수 인증서, HQ 기억, 결과 압축의 비트 수와 계산시간. Shannon entropy 및 알고리즘적 기술 길이와 섞지 않는다.
4. **열역학적 엔트로피 생성** `Σ_phys`: 물리적 계산 장치·에너지·환경이 구체적으로 정의된 뒤에만 추정한다. 가상 유니콘의 보행 시간에서 이를 도출할 수 없다.

## 정보 흐름
`HQ(t) → U(t) → prefix-check → +1 marker → return/handover → HQ(t+1)`

각 단계별로 입력 비트, 새로 발견한 정보, 보존·압축·폐기한 정보, 검사 실패 및 재수행 시간을 기록한다.

## 비용-목적함수
고정된 무결성·완료조건에서 `J = w_T T + w_C C_coord + w_B B_birth + w_R R_relayout + w_V V_verify + w_M M_memory + w_E E_erase`를 비교한다. 각 가중치의 물리 단위/정규화는 공개한다. `E_erase`는 실제 물리 장치가 없다면 개별 *논리적 삭제 이벤트* 수 같은 **대리지표**로만 기록한다.

**Landauer 원리:** 실제 열저장고 온도 `Θ`에서 이상적인 1비트의 논리적으로 비가역적인 삭제에는 최소 `k_B Θ ln 2`의 열역학적 비용이 관련된다. 이는 실제 유니콘 시뮬레이션에서 측정한 비용이 아니다. 본 연구는 모든 계산이 그 비용을 정확히 지불한다고 가정하지 않는다.

## 필수 실험
- S1: **Full-prefix recomputation vs inherited/cached certificates.** 모두 같은 산술적 검증 목표를 충족하는지 먼저 확인. 저장비트·실행시간·재검증 부담 측정.
- S2: **HQ memory**: 완전 기억 / 축약된 충분 통계 / 제한 캐시. 목적지별 완료시간과 판정 오류, 저장 비용 비교.
- S3: **Reorganisation**: 고정 배치 / 전역 재배치 / 국소 재배치. 시간·통신량·연결의 변화 측정.
- S4: **Controller network**: 독립 다리 / 모든 쌍 조율 / 인접 조율; 피드백 신호 전달량과 비용을 분리.
- S5: **같은 목표의 대조군**: 임의 라벨 / 합성수 라벨 / 소수 라벨, 동일한 초기 조건에서의 공정 비교.

## 확인해야 할 경계
- `+1`로 모든 실수를 생성했다고 주장하지 않는다. 표현 규칙과 완비화는 별도의 층위다.
- 소인수분해의 유일성 자체가 정보압축이나 엔트로피 감소를 보장하지 않는다.
- 엔트로피의 감소 또는 국소 질서 증가는 물리적 전체 엔트로피 감소와 동일하지 않다.
- 엔트로피 가중치 조절로 이미 원하는 결과를 강제하지 않도록 가중치 민감도를 보고한다.
- **개념 생성 과정**에 대응시키는 모든 해석은 *메타모형의 유비*이고 실험으로 검증된 인지 메커니즘이 아니다.
