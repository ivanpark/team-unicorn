# Team Unicorn — 한국어 안내

전체 연구의 **최상위 목적은 추상적·형이상학적 개념의 형성·구성·검증·개정을 공학적으로 탐구하는 것**입니다. Number System Universe의 효율적인 공간적 구현은 이 연구를 위한 **사고실험의 시험대**이며, 정수 징검다리는 그 안에서 Phase I의 기초공사입니다. 유니콘은 소수를 찾는 동물이 아니라 **연속적인 정수 돌을 놓는 건설팀**입니다.
