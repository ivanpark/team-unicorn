Gait Lab 0.2
1초에서 5초, 10초로

동작당 이동거리 × 완료한 동작 횟수. 시간을 늘렸을 때 생기는 단순한 반복과, 여러 다리를 관리하면서 생기는 대기·병목을 분리해 본다.

2026.10.13 · 계산 실험 · 실제 동물의 보행, 파동 간섭 또는 소수 생성 법칙을 재현하는 모형은 아니다.

01 · 다리와 동작 설정

다리동작당 거리 dᵢ요청 횟수 fᵢ / 초첫 요청 시점 / 초

dᵢ는 자유롭게 바꿀 수 있다. 기본값 5, 2, 3, 7, 11, 13은 예시일 뿐이며, 다리의 소수 라벨이 물리적 보폭을 정한다는 가정은 확정하지 않았다. 요청 빈도와 실제 완료 빈도도 다르다.

02 · 가상의 관리비용

요청 하나의 관리시간 h = λ × (k − 1)
첫 요청: φᵢ / fᵢ, 이후 매 1/fᵢ초마다 요청
시작 = max(요청 시점, 관리자 사용 가능 시점)
완료 = 시작 + h → 총거리에 dᵢ를 더함

각 동작의 추진 기여를 단순히 합산한다. 동작 도중의 부분 거리는 세지 않는다. 다리가 하나일 때 h=0인 것은 추가 협응비용만 분리하기 위한 가정이다. 설계·에너지·귀환·마찰 비용은 포함하지 않았다. 예정된 요청은 대기 중에도 계속 발생한다.

03 · 실제 완료된 거리

시간관리비용 없을 때실제 완료 거리평균거리 / 초직전 1초 거리완료 동작미완료 요청

D(5)는 5초 동안 누적된 거리다. 마지막 1초의 거리 D(5)−D(4)와 구별한다. 미완료 요청에는 관리 중인 요청도 포함된다. 모든 값은 출발 후 해당 시각까지 계산한다.

04 · 같은 설정에서 다리 수만 비교

위에 입력한 다리를 앞에서부터 k개 사용한다. 분산 시작을 선택하면 첫 동작 위상도 k에 맞춰 배치한다. 아래는 여섯 가지 구성의 비교이며 가능한 모든 gait의 최적해 탐색은 아니다.

다리 수1초 거리5초 거리10초 거리10초 미완료관리자 부하

해석할 때 지켜야 할 경계

고정된 한 다리

D(T) = d × m(T)

d와 완료 동작 수 m(T)가 양의 정수라면, D가 소수인 경우 둘 중 하나는 1이고 다른 하나는 그 소수다. d=5라면 착지 지점은 5, 10, 15, …이며 속도를 바꿔도 이 배수 조건은 바뀌지 않는다.

정수 초 단위의 반복

관리비용 0 + 초당 정수 회 반복
⇒ D(T) = T × D(1), T = 1, 2, …

D(1)>1이면 정수 T>1의 누적거리에는 소수가 나타날 수 없다. 5초·10초에서 소수가 사라지는 것은 이 설정의 산술적 결과이지 새로운 소수 법칙이 아니다.

관리 지연이나 위상을 바꿔 소수 거리가 나타나더라도, 먼저 미완료 동작과 관측 시점의 효과를 확인해야 한다. 이 모형에서 우수한 다리 수가 나와도 실제 최적 다리 수의 증명은 아니다. 비용값과 관리자 수를 바꿔 민감도를 비교한다.

관리자 부하와 병목의 의미

공유 관리자에서는 ρ = h × Σfᵢ이다. 요청은 계속 정해진 빈도로 도착하므로 ρ>1이면 장기적으로 모두 제때 처리할 수 없다. ρ<1이어도 동시 요청이나 마지막 시점의 요청 때문에 미완료가 잠깐 남을 수 있다. 다리별 관리자에서는 max(h fᵢ)를 표시한다. 이는 이 가상 대기열 모형의 조건이다.
