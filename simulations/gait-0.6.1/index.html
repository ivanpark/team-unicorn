Closed-loop Fourier Gait Lab

What happens when a unicorn senses that its legs have drifted out of coordination and adjusts their phase and cadence while moving? Reproduces the previous hypothetical gait law; adds local phase feedback, explicit disturbances, controller-effort costs and a separately adjustable inter-leg coordination price. No prime-number effect is assumed or measured here.

What is actually controlled?

Each leg follows a periodically driven max(0, sin θ) signal. The controller can observe the other legs' phase differences and vary angular velocity within ±3 rad/s. Pair-management overhead and phase-mismatch cost are assessed separately from the motion law. It does not know future phase disturbances. The zero-th leg acts as a reference.

This is a coordination experiment, not a biological leg simulator. It currently lacks destination-error feedback, prime-factor inputs, 3D geometry and intergenerational HQ learning.

Falsification-minded next steps

1. Introduce a destination-position error loop that adapts to the known target while preserving phase-continuity and charging for braking/correction.

2. Make the controller evolve using inherited previous-generation information, then compare with a controller that starts from scratch.

3. After the locomotion model is stable, add prime-labelled legs versus composite/random controls. If labels never affect the physics, no prime-specific benefit can emerge from motion alone.

4. Compare complete outbound + final +1 + return + HQ costs, not just outward motion.

Numerical integration uses 0.0025-second increments, forward Euler phase updates and baseline positive-part sine propulsion. The reference Python implementation and CSV are bundled separately.
